# Echo Show 8 (2nd gen) changelog

All notable changes to the Echo Show 8 (2nd gen) (`athena`) image are documented here. The [Echo Dot (2nd gen)](CHANGELOG-biscuit.md), [Echo Show 5 (1st gen)](CHANGELOG-checkers.md), [Echo Show 5 (2nd gen)](CHANGELOG-cronos.md) and [Echo Show 8 (1st gen)](CHANGELOG-crown.md) have their own.

## Unreleased

### Fixed
- **The image did not boot on a Show that ran R0rt1z2's LineageOS image before** ([#47](https://github.com/jxlarrea/lineageos-echo-kiosk-satellite/issues/47)). After the install the Show stopped at the fastboot screen. R0rt1z2's image puts its own files on the vendor partition, where the hardware drivers are, and release 2026.11.1 did not write that partition: it expected Fire OS's files there. The image now ships the vendor partition of Fire OS 7575.1 (PS75751/7809) as Amazon built it, and every install and update writes it. That also puts every Show on the vendor files the image is tested with, whatever Fire OS version it was unlocked from. The build takes the vendor image from a partition dump through `scripts/athena-vendor.sh`, checked against the checksum in `blobs/athena`, and `make check` fails if a release carries another one.

## 2026.11.1 - 2026-11-10

### Added
- **A first LineageOS 18.1 port for the Echo Show 8 (2nd gen).** The repository has its own device tree in `sources/device/amazon/athena`. The image is a system for the vendor partition Fire OS 7 left on the Show, with a 32-bit userspace on an arm64 kernel built from Amazon's Fire OS 7.5.7.1 source release. It boots to the home screen with the display, touch, sound, Wi-Fi and adb. SELinux is permissive, as on the other Echos. The kernel is in [android_kernel_amazon_mt8183](https://github.com/jxlarrea/android_kernel_amazon_mt8183), which the manifest pulls in.
- **wpa_supplicant built into the system image.** Fire OS's own wpa_supplicant on the vendor partition links a HIDL library Amazon added to its Android 9 VNDK, so it cannot start on Android's. The image builds wpa_supplicant from source with MediaTek's driver commands, overrides the vendor's service with it and declares its HAL in the framework manifest. A patch lets init keep the interfaces of a service definition that another one overrides.
- **Settings Fire OS's vendor partition expects from the system image.** The SELinux mapping files under the version name Fire OS's vendor policy uses (28.0.0), an empty `ro.frp.pst` because the Show has no frp partition, the USB IDs Fire OS's vendor init scripts read and the navigation bar.
- **The Kiosk Satellite Edition layer.** The image inherits the layer the other Echo Shows have: EchoService, Kiosk Satellite on first boot, the debloat, the boot animation and the memory settings. The model reads Echo Show 8 2nd Gen (KS). EchoService names the Show `echo-show-8-g2-ks` and the end of its serial. The echo canceller of the other Shows is left out, since it loads into Amazon's MT8163 audio HAL. `show.mk` has a switch for that, `ECHO_SHOW_AMZNAEC`, which only this Show turns off.
- **Amazon's vendor services stopped.** Fire OS's vendor partition starts services LineageOS has no use for. init stops the two neural network HALs, Ring's halo service, Amazon's device health attestation and its Wi-Fi and touch loggers as they start, which frees about 25 MB and leaves the vendor partition as it is.
- **adb on USB from the first boot and the layer's properties in the system image.** Fire OS's vendor partition sets the USB configuration to none, so the image sets it after the vendor's value. The layer's `PRODUCT_PROPERTY_OVERRIDES` go in `system/build.prop`, since the image ships no vendor `build.prop`.
- **Wi-Fi and Bluetooth modules in the system image.** The kernel builds Amazon's MT7663 Wi-Fi and Bluetooth drivers as modules, the image installs them in `/system/lib/modules` and its init script loads them. The modules on Fire OS's vendor partition are for Fire OS's 32-bit kernel.
- **An update zip.** `make athena` builds a zip that TWRP installs. It writes the system and boot partitions and leaves the vendor and recovery partitions alone. The build makes a recovery image only because the zip needs one defined, and the image keeps Android's recovery install service from running.
- **Volume control.** Every stream played at full volume whatever the volume was set to. Fire OS's `audio_policy_volumes.xml` on the vendor partition is in Amazon's own format, so Android 11 loaded no volume curve from it. The image ships Android's default audio policy engine configuration in `/system/etc` with speaker curves of its own. No speaker curve goes above -6 dB, because the amplifier's full output is far too loud for this speaker. Music, alarms, rings and notifications share one curve, and the system and call curves are Amazon's from Fire OS's `default_volume_tables.xml`. A patch makes the audio policy engine read it from there before it looks on the vendor partition.
- **60% master volume on a fresh install.** A fresh install starts at master volume 18 of 30, which Kiosk Satellite shows as 60%. That is the recommended level, with Kiosk Satellite's media player, intercom and assistant volumes at 100%.
- **No lock sound.** With the lock screen off, Android still played its lock sound at every boot and each time the screen turned off. The lock and unlock sounds are off.
- **No "Serial console enabled" notification.** init stops the shell on the serial port, as on the other Echo Shows.
- **The CPU stays at full clock.** init sets the `performance` governor on both CPU clusters once Android has booted, as on the other Echo Shows. With the kernel's default governor the clock dropped at idle, and Kiosk Satellite and the audio HAL took about twice the CPU time for the same work. The Show runs 1 °C warmer.
- **Double tap to wake.** Two taps within 400 ms turn the screen on. The touch chip keeps scanning while the screen is off, and the kernel's touch driver watches for the taps. Settings > Display > Tap to wake turns it on and off, as on the other Echo Shows.
- **The kernel is named after the image and its release**, such as `4.4.146-kiosksatellite-athena-2026.11.1`, as on the other Echos.
- **Apps compiled in full.** The image compiles apps with the `speed` filter at build and install time, as on the Echo Show 8 (1st gen), instead of waiting for usage profiles.
- **The link Amazon's wake word models load a library through.** `/system/lib/libtvm_modelops_ww_v5_cnet.so` points at `/data/pryon/lib`, as on the other Echos. The build made the link only as a side effect of another target, which this Show's build never ran, so the image had none. It is now an installed file of its own on every Echo.
- **Release checks.** `scripts/check-image.sh`, `tests/test-device-layers.sh` and `scripts/sign-release.sh` cover the Show: its own parts and none of another Echo's, nothing for the vendor partition, nothing that writes the recovery partition and the Wi-Fi overlay on exactly one partition.
- **The guide.** [docs/echo-show-8-2nd-gen.md](docs/echo-show-8-2nd-gen.md) covers installing, updating and the Show's settings. [Unlocking](docs/unlocking.md#echo-show-8-2nd-gen) and [Getting into TWRP](docs/twrp.md#echo-show-8-2nd-gen) have its sections and the README and credits list it. The image needs Kiosk Satellite 2026.11.16 or newer, which has the microphone gain for this Show.
- **The layer's Wi-Fi settings and DHCP name.** The layer's Wi-Fi overlay installs to the vendor partition, which this image does not ship, so the Show had none of its settings: no roaming scans that stalled streaming on networks with several access points, the real Wi-Fi MAC address and WPA2 for WPA2/WPA3 transition networks. The image now carries the overlay on the product partition (`ECHO_WIFI_OVERLAY_IN_PRODUCT`). The network stack and tethering run inside system_server as on the other Echos, which the layer's DHCP hostname overlay needs and which saves two processes.
- **Settings the other Echo Shows get from their device trees.** No battery, rotation or headset icons in the status bar, since the Show has none of them. No telephony features. Automatic brightness from the light sensor with the Echo Show 8 (1st gen)'s levels. The always-on display for `echo_service screen ambient`. Bluetooth starts as a speaker, with A2DP sink and AVRCP on and the hands-free profile off. The Camera app's preview fills the screen.
