# Echo Dot (3rd gen) changelog

All notable changes to the Echo Dot (3rd gen) (`donut`) image are documented here. The [Echo Dot (2nd gen)](CHANGELOG-biscuit.md), [Echo Show 5 (1st gen)](CHANGELOG-checkers.md), [Echo Show 5 (2nd gen)](CHANGELOG-cronos.md), [Echo Show 8 (1st gen)](CHANGELOG-crown.md) and [Echo Show 8 (2nd gen)](CHANGELOG-athena.md) have their own.

## Unreleased

### Added
- **A first LineageOS 18.1 port for the Echo Dot (3rd gen).** The repository has its own device tree in `sources/device/amazon/donut`, since amazon-oss has none for the Dot's MT8167 chip. The image boots to adb over USB on the Dot, with no screen and software rendering as on the Echo Dot (2nd gen). 
- **System as the root.** The Dot's bootloader does not run a boot image's ramdisk on a normal boot. It has the kernel mount the booted slot's system partition as the root, so the image is built that way and its boot image carries an empty ramdisk.
- **The kernel, in [android_kernel_amazon_mt8167](https://github.com/jxlarrea/android_kernel_amazon_mt8167), which the manifest pulls in.** It is Amazon's Fire OS 6.5.7.1 source release (Linux 4.4.22) with what Android 11 needs: the binder driver of Amazon's newer 4.4 kernel, the upstream files the release leaves out and `lineage_donut_defconfig`. The root mapping works without a verity key on an unlocked Dot. Android 11's adb no longer panics the kernel on its first transfer. A reboot no longer hangs in the light ring driver while its boot animation plays.
- **Wi-Fi and Bluetooth.** The kernel builds Amazon's MT7668 Wi-Fi and Bluetooth drivers from the source release as modules and init loads them from `/system/lib/modules`. Android uses the MediaTek Wi-Fi HAL and Bluetooth vendor library the Echo Shows use. `donut-btmac` gives the Bluetooth HAL the Dot's own address from Amazon's idme data. The firmware and calibration files come from the Dot's Fire OS 6 through `scripts/extract-donut-blobs.sh`, each checked against `blobs/donut`.
- **The shared Wi-Fi and Bluetooth settings.** The Dot inherits the layer every Echo shares, so it has the Wi-Fi overlay (the access point it joined is kept, the real MAC address, WPA2 on WPA2/WPA3 transition networks) and pryond. It also has the Echo Dot (2nd gen)'s Bluetooth profiles (speaker and source audio, no hands-free or phone profiles), Wi-Fi power save off, the DHCP hostname overlay and the Dot's framework patches.
- **The speaker and the microphones, with the Dot's own audio HAL.** `audio.primary.donut` in `sources/device/amazon/donut/audio` drives the kernel's sound card directly and uses none of Fire OS's audio libraries. It sets the mixer routes Fire OS uses, plays 48 kHz stereo to the speaker amplifier and reads the four microphones at 16 kHz. An app gets one microphone untouched, with no beamforming, echo cancellation or gain, since Kiosk Satellite does its own processing. `persist.donut.mic` picks which one (0 to 3, default 0). A stereo capture gets that microphone and the next one.
- **The light ring.** The Dot runs the Echo Dot (2nd gen)'s ring daemon, `biscuit-ledd`, with its animations and `biscuit-ledctl`. Both Dots have the same LED driver interface in their kernels, so the daemon moved to the layer every Echo shares (`common/leds`). It stops the kernel's boot animation once Android is up.
- **The buttons.** Volume up, volume down and the action button reach Android as keys. The privacy button is a hardware switch on this Dot: it cuts the four microphones and lights its own LED without Android, and the kernel sends Android a mute key each time the state changes.
- **The Echo Dot's Kiosk Satellite Edition layer.** The Dot inherits the layer the Echo Dot (2nd gen) has, now shared in `common/config/dot.mk` and `common/dot`: BiscuitService and `biscuit_service`, the empty launcher that leaves out what a speaker without a screen never uses, `ks-install`, the stopped services and the defaults. Shared storage stays on FUSE, since Amazon's kernel release for this Dot has no sdcardfs source.
- **Rooted adb on debuggable builds**, as on the Echo Dot (2nd gen).
- **BiscuitService follows the privacy button.** When the button switches, BiscuitService sets Android's microphone mute to match, so Kiosk Satellite sees the real state. While privacy is on, nothing unmutes the microphones: `biscuit_service mute off` and Kiosk Satellite's unmute leave them muted until the button is pressed again.
- **More free RAM, with the Echo Dot (2nd gen)'s kernel memory changes.** The kernel's page map covers 128 MB sections instead of one 1 GB section that is half empty, which gives Android 8 MB more RAM. KSM is on, so identical pages in different processes are kept once. A fresh install has about 322 MB available after boot, before Kiosk Satellite is installed.
- **Kiosk Satellite installs itself and becomes the device owner.** The Dot declares Android's tablet feature list, as the Echo Dot (2nd gen) does. Without the device admin feature in it, `ks-install` could not make Kiosk Satellite the device owner and Android killed it on every boot.
- **Apps get their shared storage folder.** Android 11 tags each app's folder on shared storage with an ext4 project ID, which this Dot's 4.4 kernel does not have, so no app got its `Android/data` folder. vold now carries on without project IDs on such a kernel (`patches/donut/system/vold`).
- **Kiosk Satellite stays up after a reboot.** On FUSE shared storage Android kills an app each time its permission to install packages is set, even to the value it already has. `ks-install` set it on every boot, right after Kiosk Satellite had started. It now sets only the app ops that are not allowed yet. When it restores one that was taken away and that stops Kiosk Satellite, it starts Kiosk Satellite again.
- **Kiosk Satellite applies its settings for this Dot.** It only does so on an image that says it takes system updates through BiscuitService (`ro.biscuit.ota=1`), which the image now sets. That gives the Dot Kiosk Satellite's microphone gain for its model. BiscuitService looks for releases under the Dot's own codename.
- **The ambient light sensor.** The Dot runs the Echo Dot (2nd gen)'s sensor HAL, now shared in `common/sensors`, which also reads this Dot's TSL2572. Kiosk Satellite gets the light level in lux.
- **The line out jack.** While something is plugged into the jack, the Dot plays through it and its own speaker is off. The audio HAL follows the kernel's jack detection.
- **System updates through BiscuitService and TWRP, as on the Echo Dot (2nd gen).** The Dot's TWRP is the same version with the same slot tool, so both Dots share one updater (`common/dot/ota`, `common/dot/releasetools`). Slot A gets the update first and slot B once slot A has booted. The release is downloaded to `/data/biscuit-ota`, since the Dot's `/cache` holds 27 MB. The update zip writes only the boot and system partitions of the slot it installs into, and Android's service that could write the recovery partition is off. The Dot's bootloader starts TWRP a second time after a stay in TWRP of more than a few seconds, so the update leaves TWRP a script that reboots for that second start.
- **A guide.** [Echo Dot (3rd gen)](docs/echo-dot-3rd-gen.md) covers installing from stock Fire OS, updating and the settings. [Unlocking](docs/unlocking.md#echo-dot-3rd-gen) links R0rt1z2's XDA thread for the unlock and [Getting into TWRP](docs/twrp.md#echo-dot-3rd-gen) covers the slots and leaving TWRP, which can take two reboots on this Dot.
- **Image checks.** `make check DEVICE=donut` checks the image and its update zip: the Dot's own parts and none of the Echo Shows', no Pryon files, and a zip that writes only the boot and system partitions of the slot TWRP booted on.
